연출 바꾸기 — 카피바라 전진 · 보스만 · 다음 맵 이동

2026-11-15 · 같은 세이브·같은 순서로 찍은 고치기 전 ↔ 고친 뒤 (게임 화면 그대로, 초당 15장) · 체크 = "이대로 좋음", ✎ 의견 = 고칠 점
제가 이렇게 해석했습니다 (다르면 의견 칸에 적어 주세요)
  1. 카피바라 전진 = 카메라는 그대로, 카피바라는 제자리에서 걷고 땅(맵)이 왼쪽으로 흘러감. 앞에 좀비가 사정거리 안에 오면 멈춰서 쏘고, 다 잡으면 다시 걸어감.
  2. 좀비떼가 뭉쳐 있음 = 6~10마리가 한 덩어리로 앞에서 기다림. 완전히 서 있으면 밋밋해서 덩어리째 아주 천천히(0.4칸/초) 다가오게 함 — 0 으로 바꾸면 제자리에서 꿈틀.
  3. 보스전엔 보스만 = 보스가 나오면 남은 졸개는 오른쪽으로 도망가고(보상 없음) 보스전 동안 졸개가 안 나옴. 보스가 화면에 들어올 때까진(다가가는 동안) 보스 시간 30초가 안 줄어듦.
  4. 다음 맵으로 이동 = 보스를 잡았을 때만 (보스 = 챕터 마지막 = 맵이 바뀌는 때). 보통 스테이지는 그대로 걸어가며 넘어감.
  5. 던전(도전 · 비밀던전 · 보스 던전)은 예전 그대로 · 좀비가 카피바라를 공격하지 않는 것도 그대로.
  6. 바뀐 것마다 Config 값 하나로 예전으로 되돌릴 수 있음 (맨 아래 표).
    1. 앞에 좀비가 없으면 분대가 걷는 그림 + 땅이 1.6칸/초로 흘러감 (걷는 동안에도 사정거리 안 좀비는 쏨)
    2. 어느 카피바라든 사정거리 x 0.5 안에 좀비가 들어오면 멈춰서 쏨 (= 화난 얼굴이 나오는 거리라 멈출 때 화난 얼굴) → 다 잡으면 다시 걸음
    3. 무리 = 6~10마리 타원 덩어리(10마리면 가로 약 3칸), 무리 사이 3.5칸, 높이는 위·가운데·아래를 돌아가며
    4. 맵은 같은 판을 좌우로 뒤집어 이어 붙여 끝없이 흘러감 (그림 양 끝 테두리 줄은 잘라 냄)
    1. "보스 등장!" → 졸개는 오른쪽으로 도망 → 분대가 걸어가 보스를 만남 (보스는 맨 앞 카피바라에서 4칸 앞에서 멈춤)
    2. 보스가 화면에 들어오면 보스가 먼저 한마디 → 카피바라가 받아침 (받아칠 말이 없으면 리더가 예전 "보스다!! 조심해!!" 줄)
    3. 싸우는 동안 6~9초마다 보스 도발 한마디 · 체력이 절반 아래로 떨어지면 "으윽... 제법인데?" 같은 말 한 번
    4. 시간 안에 못 잡으면 보스가 "크하하! 더 강해져서 와라!" 하며 물러남
    1. 보스가 쓰러지며 한마디 ("내가... 지다니...") — 1.1초 서 있음
    2. 리더 "스테이지 클리어!" 하며 분대가 점점 빨리 달려 나감 (최고 7칸/초, 쓰러진 보스는 뒤로 지나감)
    3. 싸우는 땅이 어두워짐 (위 UI 는 그대로 보임) → 다 덮이면 새 챕터 맵 + "Stage 2-1 / 오염된 해안" 알림 → 밝아지며 다시 천천히 걷기
    4. 모두 3.2초 · 이동 중엔 좀비가 안 나옴
