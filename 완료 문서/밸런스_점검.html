5미션 목표가 실제 진행과 안 맞음

  • 좀비 처치: 표는 단계 = 챕터라고 보고 150단계 62억 마리. 실제로는 150챕터까지 약 6만 마리 → 14단계에서 멈춤 (한 스테이지 21마리 + 반복 사냥).
  • 스테이지 클리어: 137단계부터 목표가 750 을 넘어 영원히 못 받음.
  • 총알 합성: 목표 3·10·25… 인데 실제 합성은 게임 전체 10~30번 → 2~3단계에서 멈춤.

6광고 x3 의 영향이 매우 큼

공격력·골드 x3 을 계속 켜 두면 지금 표 58시간 → 8시간 (7배 빠름). 고친 후보에서도 121 → 42시간. 광고 1편 = 5분, 최대 1시간 누적이라 부지런한 사람은 거의 항상 켤 수 있습니다. 의도한 정도인지 정해 주세요 (예: 배율 x2, 또는 공격력만).

7작은 것들

  • 슬롯 강화의 골드 비용(최대 451억)은 10챕터 이후 거의 공짜 — 골드 칸이 의미 없음.
  • 보스 던전 150레벨은 하루 3장이라 최소 50일 — 지금은 게임이 14일에 끝나 대부분 못 씀.
  • 상점 골드 상자(다이아 100 = 좀비 600마리 골드)는 반복 사냥 약 7~20분 값 — 다이아 100(D 총알 1개)보다 싸게 느껴짐.

  • 스테이지 보스 30초 · 체력 15~22배 = 강화를 재촉하는 문 역할을 잘 함 (일반 좀비는 계속 잡히는데 보스에서 막힘).
  • 인벤토리 15칸 = SSU 까지 합성해도 칸이 모자라지 않음.

4. 고치는 방법 제안

  1. 골드 강화 구간 — 위 후보(또는 원하는 길이에 맞춘 값)로 Player.xlsx 의 Gold_Upgrade_1500 을 다시 만듦. 기획 표 원본이라 허락해 주시면 수정하겠습니다.
  2. 공격속도 상한 — 0.06초를 넘는 속도는 공격력으로 바꿔 줌(코드). 속도 강화가 끝까지 의미 있고, 무기 종류 불균형도 사라짐. 또는 속도 강화에 최대 레벨을 두고 MAX 표시.
  3. 다이아 — 후반 총알을 다이아만으로 모을 수 있게: 뽑기 등급을 챕터에 따라 올림(예: 30챕터부터 C, 60챕터부터 B …) 또는 도전·미션 보상을 챕터에 비례해 키움. 결제로 채울 부분이라면 그 비율을 정해 주세요.
  4. 미션 목표 — 실제 진행 속도에 맞게: 처치 = 1단계당 약 1.5챕터 분량(약 150~400마리씩 증가), 스테이지 = 750 에서 멈춤, 합성 = 1·2·4·8… 처럼 작게.
  5. 광고 배율 — 의도 확인 (x3 그대로 / x2 / 공격력만).
  6. 광산 보상을 보스 던전 수준 쪽으로 올리고, 슬롯 강화 골드 비용은 빼거나 골드 성장에 맞춤.

5. 계산 방법 · 가정

  • 게임 코드와 같은 식: 피해 = 총알 공격력 x 골드 강화 x (1+스킨) x (1+보급품) x 슬롯 강화 x 버프, 발사 간격 = 간격 ÷ 공속 (최소 0.06초), 보스 피해 = 보급품·슬롯 강화 보스 피해. 표 끝 너머 = 마지막 성장률.
  • 좀비는 0.7초마다 1마리 이하로 나옴(동시 8마리) → 아무리 세도 한 스테이지 약 17초. 좀비 체력·골드 = 그 챕터에 나오는 종류의 비율 평균.
  • 하루 4시간 켜 둠(오프라인 보상 없음). 날마다 광산 2장(맞히는 수에 비례), 보스 던전 3장(이길 수 있을 때만), 도전은 깰 수 있게 되면 바로.
  • 골드 = 가장 싼 강화부터(속도는 상한이면 안 삼). 다이아 = "보스 DPS 증가 ÷ 값"이 가장 큰 것부터(총알은 낮은 칸부터, 합성 결과 종류는 평균, 슬롯 강화는 성공률 반영).
  • 보수적으로 본 것: 관통·레이저·미사일이 여러 마리를 한 번에 맞히는 것은 안 셈. 낙관적으로 본 것: 산탄은 전부 맞음, 사람이 최적으로 삼.
