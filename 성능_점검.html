자동 측정(PlayTest.RunPerf): 51스테이지 · 레이저/미사일/산탄총 · 한 바퀴 = 스테이지 사냥 → 창 4개 → 도전 → 스테이지 → 비밀던전 → 스테이지 → 보스 던전, 3바퀴. PC 에서 잰 값이라 폰은 몇 배 느립니다 — 전·뒤 차이와 멈칫하는 순간(최악)을 보세요.

표 읽는 법
  • 최악 프레임 ms = 그 구간에서 가장 오래 걸린 한 프레임(화면 그리기 포함). 60프레임이면 한 프레임 16.7ms — 이걸 넘으면 그만큼 멈칫. PC 에디터는 화면 그리기 때문에 평소에도 20ms 안팎.
  • 게임 코드 최악/평균 ms = 우리 스크립트만 쓴 시간.
  • 쓰레기 메모리 KB/프레임 = 게임 코드가 한 프레임에 만들고 버리는 메모리. 쌓이면 몇 초마다 메모리 청소로 멈칫.
  • 물체 수 = 바퀴가 갈수록 늘면 누수. 전·뒤 모두 바퀴마다 늘지 않았습니다. 고친 뒤 더 많은 것은 의도한 것 — 미리 만들어 닫아 둔 창 8개 + 다시 쓰려고 모아 둔 효과·쓰러진 좀비의 꺼 둔 뼈대.
  • 쓰레기 메모리: "스테이지 사냥(처음)" 의 1000KB 는 장면을 불러오는 첫 프레임 몫이라 빼고 보세요. 평소(프레임당 1KB 안팎)는 크게 줄지 않았습니다 — 남은 몫은 피해 숫자 글자 등이고, 메모리 청소는 "나눠 하기"(incremental)가 켜져 있어 한 번에 크게 멈추지 않습니다.

찾은 원인 → 고친 것

  1. 처음 던전에 들어갈 때 멈칫 (PC 136ms) — 보스·던전 배경음(38초)을 들어가는 순간 계산했음 → 켤 때 따로 일꾼(스레드)이 미리 계산 → 22ms
  2. 창(총알·보급품·코스튬·상점…)을 처음 열 때 멈칫 (PC 103ms) — 창을 그때 만들고 한글 글자도 그때 그렸음 → 켜는 로딩 안에서 8개 창을 미리 만들고 글자까지 그려 둠 → 20ms
  3. 사냥 중 좀비 무리가 나올 때 툭툭 끊김 (게임 코드 최악 7~12ms) — 6~10마리를 한 프레임에 한꺼번에 만들었음 → 한 프레임에 2마리씩 (오른쪽 화면 밖이라 보이는 건 같음) → 2~2.5ms
  4. 5초마다 세이브를 폰 저장소에 바로 씀 — 자동 저장은 메모리에만, 저장소 쓰기는 30초마다 · 앱을 나가거나 끌 때 · 보상·구매 같은 저장은 예전처럼 바로 (PC 에선 차이가 안 보임 — 폰 저장소가 느릴 때를 막는 것)
  5. 매 프레임 버리는 메모리 줄임 — 총알 한 발마다 그림 찾기 글자 4개 · 레이저·미사일마다 대상 목록 복사 · 맞을 때마다 불꽃·폭발 물체를 새로 만들고 지움(→ 다시 씀) · 0.1초마다 금화·강화 카드 글자 새로 만듦(→ 바뀔 때만) · 쏠 때마다 스킨·보급품 합 다시 셈(→ 가진 목록이 바뀔 때만)
  6. 화면(UI) 다시 모으기 줄임 — 피해 숫자가 흐려질 때 글자·테두리를 매 프레임 다시 만들던 것(→ 투명도만) · 피해 숫자·날아가는 돈을 따로 판(Canvas)에 · 버튼·아이콘이 같은 크기를 매 프레임 다시 넣던 것
  7. 쓰러진 좀비 — 안 보이는 뼈대를 1.15초 동안 계속 휘던 것 멈춤

오래 해도 물체 수·메모리가 늘어나는 누수는 없었습니다 (3~5바퀴 내내 같은 범위). "오래 하면 밀린다"는 느낌은 ① 콘텐츠를 처음 들어갈 때마다의 멈칫 ② 사냥 중 무리 나올 때 끊김이 겹친 것으로 보이고, 폰이 오래 돌아 뜨거워지면 성능을 낮춰 이런 순간이 더 크게 느껴집니다.
